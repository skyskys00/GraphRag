## 结论与观察

1. **v5.6 → v5.7 最大跃升**：table_numeric precision 0.0625 → 0.2188（+250%），说明表格内容从 HTML 改 Markdown 对 embedding 质量提升显著。
2. **v5.7 → v5.8 持续改善**：table_numeric precision 0.2188 → 0.2812（+28%），切分调细 + 数字 token 追加有效。
3. **RRF 阶段 table boost 无效**：×1.2 和 ×2.0 结果完全相同 —— 因为 top40 候选里 table chunk 已足够多，最终排名由 rerank 决定。
4. **当前瓶颈在 rerank**：纯数据型表格（如市场规模表）在 rerank 阶段得分低，被语义相近的段落挤出 top8。
5. **下一步方向**：rerank 后 table boost / 优化表格 dense 表示 / 数字精确匹配加分。
