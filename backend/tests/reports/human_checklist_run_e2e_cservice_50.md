## 3. CS-FC-007 [fact_cross_doc / hard] LLM 判定 correctness=1.0
**问题**：行业报告中提到的「首问解决率从 40% 提升至 70% 以上」与公司 PRD 中的 FCR 目标有什么关系？公司当前 FCR 实际水平如何？
**标准答案**：行业报告（D5）中的「首问解决率」即 PRD（D2）中的 FCR（First Contact Resolution，首次联系解决率），二者是同一概念的不同表述。行业水平从 40% 提升到 70%+ 代表大模型技术驱动下的行业进步。公司 PRD 对 FCR 设定分层目标：整体 ≥ 85%、智能问答 ≥ 70%。从 Q3 运营数据（D3）看，公司整体 FCR 实际为 78.5%，低于 85% 目标。
**key_facts**：首问解决率 = FCR = 首次联系解决率（同一概念）；行业水平：40% → 70%+（LLM 驱动）；PRD 目标：整体 ≥ 85%、智能问答 ≥ 70%（分层）；Q3 整体 FCR 实际 = 78.5%，未达 85% 目标
**系统答案**：先总述：行业报告中的「首问解决率从 40% 提升至 70% 以上」描述的是 LLM 技术突破带来的行业层面成效，而公司 PRD 中的 FCR 目标是在此基础上设定的企业内部考核目标，两者在数值区间上存在承接关系。公司当前 FCR 实际水平为 78.5%，尚未达到 PRD 设定的整体目标。

具体分析如下：

**一、两者的关系**

- 行业报告指出，大语言模型大幅提升语义理解、多轮对话与知识推理能力，使得智能客服从"答非所问"进化为"基本可用"，真实场景下的首问解决率从 40% 提升至 70% 以上 [1]。
- 公司 PRD 设定的 FCR 目标为：智能问答首问解决率 ≥ 70%，整体首问解决率 ≥ 85% [2]。FCR 定义为客户首次联系就解决问题的比例，无需二次或多次联系 [4]。
- 可以看出，PRD 中智能问答 FCR ≥ 70% 的目标与行业报告提到的"70% 以上"处于同一水平线；而 PRD 整体 FCR ≥ 85% 的目标则高于行业报告所述水平。

**二、公司当前 FCR 实际水平**

- 2026 年第三季度，公司首问解决率（FCR）为 78.5% [3]。
- 环比来看，FCR 从 Q2 的 74.3% 提升至 Q3 的 78.5%，提升 4.2 个百分点 [5]。
- 但从目标完成情况看，FCR 目标值为 ≥ 85%，当前 78.5% 属于**未达标*
**裁判理由**：答案准确指出行业报告首问解决率即PRD中的FCR，PRD分层目标整体≥85%、智能问答≥70%，以及当前实际78.5%未达整体目标，关键事实均与标准答案一致。

## 4. CS-FC-004 [fact_cross_doc / medium] LLM 判定 correctness=0.25
**问题**：投诉处理中「升级流程」有几种不同含义？请分别说明。
**标准答案**：投诉升级在不同语境下有两种含义：①投诉分级升级（SOP D1）——按投诉等级（三级→二级→一级）的常规升级机制，包括超期升级、情绪升级、技术升级、跨部门升级四种触发条件；②跨部门升级（SOP D1 §5.1 第 4 条 + PRD D2 的跨部门协作模块）——涉及研发、供应链等其他部门协调时的升级路径，由客服项目经理统一拉群跟进，工单系统 v3.0 支持跨部门工单流转。
**key_facts**：含义一：投诉分级升级（三级→二级→一级）；触发条件：超期/情绪/技术/跨部门 四种；含义二：跨部门升级（客服→其他部门）；执行方式：客服项目经理拉群，工单系统 v3.0 流转
**系统答案**：根据检索材料，投诉处理中的「升级流程」主要出现在「升级机制」部分，包含升级触发条件的分类以及升级后的处理流程两层含义。具体如下：

**一、升级触发条件（即升级的类型）**

材料明确列出四类升级触发条件：[2]

1. **超期升级**：任一环节超出规定时效未完成，系统自动升级至上一级主管，并发送提醒通知。[2]
2. **情绪升级**：客户明确表达不满升级，如提及投诉至消费者协会、媒体曝光、法律诉讼等，须立即升级至客服总监。[2]
3. **技术升级**：售后工程师在2小时内无法定位问题原因，须升级至技术支持中心协助排查。[2]
4. **跨部门升级**：涉及研发、供应链等其他部门协调的投诉，由客服项目经理统一拉群跟进，每日同步进展。[2]

**二、升级处理流程**

升级工单触发后，接收方须在30分钟内确认接收并启动处理，处理完毕后须将处理结果回传至原工单系统，形成闭环记录。[3]

综上，从材料来看，「升级流程」一是指四类升级触发条件（超期、情绪、技术、跨部门），二是指升级工单触发后的接收与闭环处理流程。[2][3]

需要说明的是，材料中「升级流程」仅指上述内容，未涉及其他含义。
**裁判理由**：答案仅正确复述了四类触发条件中的名称，却将其错误归纳为“升级流程”的两层含义之一，遗漏了标准答案核心的“投诉分级升级（按等级三级→二级→一级）”和“跨部门升级（跨部门工单流转）”两种含义，多个关键事实点与标准答案不一致。
