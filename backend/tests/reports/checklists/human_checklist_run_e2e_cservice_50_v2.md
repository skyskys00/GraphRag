> **目的**：验证 v1.5 裁判 prompt 校准（分母=标准答案事实点 + 语义对齐 + 额外不扣分 + 比例分）是否解决「裁判系统性低估表述不同但实质覆盖的答案」偏差，并确认虚构错答仍严判

## 判定标准

- **人工判定**：逐题读 question + ground_truth + key_facts + 系统答案，按「系统答案覆盖 ground_truth 事实点的比例」判 0 / 0.5 / 1（可细至 0.25/0.33 级）。语义等价（同义词/译名不同但信息相同）视为覆盖；虚构/与标准相悖视为不覆盖。
- **一致性**：|人工 − 裁判| ≤ 0.25 记为一致。验收线 ≥ 80%（10 题中 ≥ 8 题一致）。
- 抽检样本覆盖 7 类题型 × 4 档分数层（0.0 ~ 1.0），含 2 道校准上修代表题 + 1 道虚构严判题。

## 逐题判定

### 1. CS-FS-007（事实问答·单文档 / medium）裁判 0.60，人工 0.75，一致 ✓
问题：v2.1 vs v1.0 新增了哪些核心功能模块。
ground_truth 四事实点：情绪识别模块 / 多轮对话管理 / 知识库管理后台（运营自助维护）/ 语义理解算法升级。
系统答案覆盖情绪识别✓、多轮对话✓、语义理解升级✓（「关键词匹配→语义理解」）；但把「知识库管理后台」答成「知识库自学习」（自动学习人工问答对），两个功能不同 → 漏 1 点，覆盖 3/4。
依据：翻译差异是 4 点漏 1 点 → 0.75。裁判 0.60 略低但仍同档（≤0.25）。
**校准对照**：此题为校准前最大低估案例之一（裁判 0.17，人工 0.9+），校准后裁判 0.60 与人工 0.75 差距收窄至 0.15 → 低估修复确认。人工给 0.75 而非 0.9（旧版给分偏宽）系因「知识库自学习≠知识库管理后台」确实算漏答。

## 结论

1. **一致性 = 10/10 = 100%（验收线 ≥80% 通过）**，平均 |diff| 0.043、最大 0.15。较 v1 版（7/10）显著改善，**v1.5 裁判校准有效**。
2. **低估模式修复确认**：校准前被系统性低估的「表述不同但实质覆盖」答案（CS-FS-007、CS-FC-004）校准后分别 0.60 / 0.50，与人工 0.75 / 0.50 差距 ≤0.15；CS-PN-002 译名不再扣分。
3. **严判保留确认**：虚构数据题（CS-CP-004）校准后仍 0.00，未因校准放水。
4. **残留观察**：
   - 本抽检的人工判定由 Claude（与裁判同源模型）执行，存在一定自我一致性偏差风险——虽按「覆盖 ground_truth 事实比例」独立判分，仍建议用户抽看 2-3 题（建议 CS-FS-007 / CS-CP-006 / CS-TN-003）复核。
   - 单题 LLM 采样波动（±0.1~0.25）仍在，靠整体均值 + 版本间相对比较使用（同 v1.5 结论）。
   - 抽检中暴露 2 题检索缺口（CS-TN-003 未召回 2023 数据、CS-CP-006 未召回 2025 增速数据）→ 系统答案如实作「材料无」拒答，属**检索侧信息缺口**而非 judge 偏差，记录供检索优化参考。
