## 判定标准

- **人工判定**：逐题读 question + ground_truth + key_facts + 系统答案，按「系统答案覆盖 ground_truth 事实点的比例」判 0 / 0.5 / 1（可细至 0.25 级）。语义等价视为覆盖；虚构/与标准相悖视为不覆盖。
- **一致性**：|人工 − 裁判| ≤ 0.25 记为一致。验收线 ≥ 80%（10 题中 ≥ 8 题一致）。
- 样本覆盖 6 类题型 × 高分/中分/低分/异常组，含 2 道低分题（q016 correctness=0.6、q008=0.89）+ 1 道拒答题（q029）+ 1 道 citation 异常题（q024 citation_accuracy=0.2）。
