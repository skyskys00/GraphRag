**版本：** v2.0
**发布部门：** 信息技术部（IT部）
**生效日期：** 2026年2月1日
**修订日期：** 2026年6月20日

---

## 第一章 总则

### 1.1 目的

为规范公司IT设备的采购、领用、使用、维护及报废管理，保障公司信息系统安全运行，提高设备使用效率，特制定本规范。

### 1.2 适用范围

本规范适用于公司所有员工使用的台式电脑、笔记本电脑、显示器、打印机、移动存储设备、网络设备及其他IT外设。

### 1.3 管理部门

IT部为IT设备管理的归口部门。

- **IT主管**：李四，负责设备采购审批、资产管理、安全策略制定。
- **运维工程师**：周浩、吴宇，负责设备安装、维护、报修处理。
- **资产管理员**：郑小晴，负责设备台账、标签管理、盘点。

### 1.4 管理原则

1. **统一配置、按需分配**：IT设备由IT部统一采购配置，根据岗位需求分配。
2. **专人专管、责任到人**：使用人对领用设备负保管责任。
3. **安全第一、合规使用**：所有设备须遵守公司信息安全规定。
4. **台账管理、全程追溯**：每台设备从采购到报废全生命周期可追溯。

## 第二章 设备分类与配置标准

### 2.1 设备分类

| 类别 | 包含设备 | 管理方式 |
|------|----------|----------|
| **A类（固定资产）** | 台式电脑、笔记本电脑、一体机、显示器（≥24寸）、打印机、投影仪、服务器、网络设备 | 固定资产登记，使用期限≥3年 |
| **B类（低值耐用品）** | 键盘、鼠标、耳机、摄像头、小型显示器（<24寸）、U盘、移动硬盘 | 台账管理，以旧换新 |

> **说明：** C类耗材的领用流程及费用核算参照《办公用品领用管理办法》执行，由IT部负责库存管理。

## 第三章 设备领用流程

### 3.1 新员工入职设备

1. HR在新员工入职前3天，在OA系统提交"新员工IT设备申请"。
2. IT部根据岗位配置标准准备设备。
3. 入职当天，IT运维工程师完成系统部署及软件安装。
4. 员工确认设备完好后，在设备领用单上签字确认。
5. 设备信息录入IT资产管理系统，绑定使用人。

> 办公电脑之外的办公用品，按《办公用品领用管理办法》申领。

### 3.2 临时设备领用

员工因项目需要临时借用设备（如备用笔记本、投影仪、移动硬盘等）：

1. 在OA系统提交"IT设备临时借用申请"，注明借用事由及预计归还日期。
2. 经部门经理审批后，IT部安排设备。
3. 借用期限一般不超过15天，特殊情况可申请延长。
4. 归还时IT部检查设备状态，有损坏按规定处理。

### 3.3 出差携带设备

员工出差需携带公司IT设备的：

- **日常使用的工作电脑**：已登记在本人名下，直接携带即可。
- **额外设备**（如投影仪、便携打印机等）：按临时设备借用流程办理。
- **出国出差**：须提前在IT部备案，确认设备符合目的地海关规定。
- 设备在出差期间遗失或损坏的，按本规范第六章相关条款处理。
- 差旅途中设备相关费用报销，按《员工差旅报销管理制度》执行。

### 3.4 设备更换

设备满足以下条件之一的，可申请更换：

1. 使用年限满3年且性能无法满足工作需要的。
2. 多次维修仍无法正常使用的。
3. 岗位调整后配置不匹配的。
4. 出现不可修复的硬件故障的。

更换流程：员工提交申请 → 部门经理审批 → IT部评估 → IT主管审批 → 交回旧设备 → 领取新设备。

## 第四章 使用与维护

### 4.1 使用规范

1. 公司设备仅限用于工作用途，不得用于私人商业活动。
2. 不得私自拆卸、改装设备硬件。
3. 不得安装未经IT部批准的软件，尤其是盗版软件。
4. 不得关闭杀毒软件和安全防护工具。
5. 设备密码须符合复杂度要求，每90天更换一次。
6. 离开工位时须锁屏，重要文件须加密存储。

### 4.2 软件安装

- 办公软件（Office、浏览器等）由IT部统一部署。
- 专业软件须提交申请，经IT部审核版权合规后安装。
- 禁止私自下载安装来源不明的软件。
- 禁止使用公司设备访问非法网站或从事网络违法活动。

### 4.3 故障报修

1. 设备出现故障时，在IT服务台提交工单（OA → IT服务 → 故障报修）。
2. 一般故障：1个工作日内响应，2个工作日内修复。
3. 紧急故障（影响关键业务）：30分钟内响应。
4. 无法现场修复的，IT部提供备用机，设备送修。
5. 维修费用在保修期内的由供应商承担；过保且非人为损坏的由公司承担。

### 4.4 日常维护

- **系统更新**：IT部统一推送系统及软件更新，员工不得推迟超过7天。
- **病毒查杀**：杀毒软件自动运行每周全盘扫描，员工不得关闭。
- **数据备份**：重要文件须存放在公司云盘，本地数据不做备份承诺。
- **季度巡检**：IT部每季度对办公设备进行一次健康检查。

## 第五章 安全与保密

### 5.1 信息安全

1. 公司设备存储的所有数据均为公司资产，员工不得私自拷贝外传。
2. 涉及客户数据、财务数据、源代码等敏感信息的设备，须启用磁盘加密。
3. 设备丢失须立即报告IT部，IT部将远程锁定并擦除数据。
4. 离职员工须在离职当天归还所有IT设备并清除个人数据。

### 5.2 网络安全

1. 公司设备连接办公网络须通过身份认证。
2. 外部网络（咖啡厅、机场等）办公须使用公司VPN。
3. 不得在公共网络环境下传输敏感数据。
4. 禁止私自搭建热点或接入未授权网络设备。

### 5.3 数据保密

- 严禁将公司内部数据上传至个人云盘、个人邮箱。
- 打印涉密文件须全程在场，打印后及时取走。
- 废弃的存储设备须由IT部统一销毁，不得自行丢弃。

## 第六章 遗失、损坏与赔偿

### 6.1 遗失处理

设备遗失后：

1. **立即报告**：24小时内向IT部和直属上级报告。
2. **安全处理**：IT部立即远程锁定、擦除设备数据，禁用相关账号。
3. **报警**：价值5000元以上的设备遗失，应同时报警。
4. **责任认定**：IT部会同行政部、HR进行责任认定。

### 6.2 赔偿标准

| 责任类型 | 情形 | 赔偿比例 |
|----------|------|----------|
| **正常损耗** | 设备自然老化、非人为故障 | 0%（公司承担） |
| **疏忽大意** | 未妥善保管导致遗失（如忘在出租车、咖啡厅） | 30% |
| **严重过失** | 未锁门/未锁屏导致被盗、放置在公共场所无人看管 | 50% |
| **故意损坏** | 故意摔砸、私自拆解导致损坏 | 100% |
| **用于私人活动损坏** | 私用期间损坏或遗失 | 100% |

赔偿金额按设备当前净值计算（净值 = 原值 × (1 - 已使用月数/36)，最低为原值的20%）。

### 6.3 离职归还

员工离职时：

1. 归还所有名下登记的IT设备（电脑、显示器、外设等）。
2. IT部检查设备外观及功能是否正常。
3. IT部清除设备上的个人数据，重置系统。
4. 设备有损坏的按赔偿标准处理。
5. IT部在OA系统确认后方可办理离职手续。

## 第七章 设备报废与处置

### 7.1 报废条件

设备满足以下任一条件可申请报废：

1. 使用年限超过5年且性能无法满足基本需求的。
2. 维修费用超过设备现值50%的。
3. 因技术升级无法适配现有系统的。
4. 存在不可逆安全隐患的。

### 7.2 报废流程

1. IT部每半年组织一次设备盘点，提出报废清单。
2. 报废清单经IT主管审核 → 财务部复核（资产核销）→ 行政总监审批。
3. 审批通过后，IT部进行数据彻底清除。
4. 报废设备统一交由行政部处置（回收/捐赠/销毁）。
5. 财务部从固定资产台账中核销。

### 7.3 年度盘点

IT部每年12月进行IT设备全面盘点：

- 核对资产台账与实物是否一致。
- 更新设备状态（在用/闲置/维修中/已报废）。
- 生成盘点报告，报IT主管及财务部。
- 盘盈盘亏按公司固定资产管理制度处理。
