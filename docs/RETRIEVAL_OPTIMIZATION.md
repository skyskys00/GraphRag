## 已探明无效 / 不落地的方法

> 按「探底三条纪律」归档：结论一律进 CHANGELOG + 对比表；一次性脚本留 `scripts/` 或删除。

| 方法 | 版本 | 判定 | 一句话原因 |
|---|---|---|---|
| 表格 boost ×1.2 / ×2.0 | ~~v5.8.2 / v5.8.2b~~ | **无效弃用** | RRF 融合后表格 chunk 加权，结果与 v5.8 完全一致——top40 中表格已够多，排名由 rerank 决定 |
| table_numeric_boost=2.0 | ~~v5.11~~ | **无效弃用** | 数字型问题表格块 numeric_match ×2.0，检索结果逐字节一致 |
| numeric_match bug 修复 + 增益 | ~~v5.12~~ | **无效弃用** | 修复 1 位数字过滤 + 空格不匹配后仍叠加 boost → 零效果 |
| structured 补召回（B 方案） | v5.20 探底 | **不落地（已回滚）** | query 实体匹配表 cell 能补进候选池，但** rerank 全部压出 top5**，30 题指标逐位一致 |
| 摘要/前缀注入 sparse 向量（NL_SUM→sparse） | v5.20 探底 | **不落地（三连）** | 全量 -0.94pt ~ +0.0026，不过 ±1pt 验收线 |
| LLM 表格摘要进 rerank 输入 | v5.20 探针 | **不落地（与规则版同构）** | 单块 rerank 0.154→0.714（rank12→6），但 **top5 名单逐位不变**——分数提高不改变排名结构（数据复原见对比表文末补档小节） |
| children 展开（M2 构建期静态引用） | 2026-09-27 探底 | **不落地（三连）** | 全量 30 题 0 救回；孤儿标题块（≤11 字）向量检索先天难命中，触发点不存在 |
| neighbor ±K 展开（检索期） | 2026-09-27 探底 | **不落地（三连）** | 仅 q008 救回 1 fact（029 rank5 ±3 拉入 030），28 题新增 ~2290 块，噪声比远超验收线 |

**贯穿性病根（决定上面大多方法无效）**：cross-encoder（bge-reranker-v2-m3）对数字/专名表格语义失明——rerank 输入文本怎么喂（列名 / 摘要 / 特征）都只改变**分数量级**、不改变**排名结构**。召回层手段（结构化 / 前缀 / 摘要）都无法抵消 reranker 失明，破局只能靠 reranker 侧（= v5.21 LLM 终审，评测侧已做）或换赛道。

## 已知缺口（不解决 / 搁置 / 待修）

| 缺口 | 定性 | 状态 |
|---|---|---|
| q008 6.2 赔偿表（030/031） | 连 `fused_top40` 候选池都没进——**召回/融合边界缺口**，非 reranker 层（LLM 终审也救不了池外块） | **承认搁置**。e2e 已证明系统诚实拒答不幻觉，可用性不受损。若未来要缓池塘外表格子块，唯一保留的最小成本路径：对「已命中表格族块」做 ±1 或按表边界展开 |

## 维护纪律

1. **新方法落版 / 弃用** → 本文档加一行（含版本 + 状态判定）+ CHANGELOG 登记版本 + 对比表归档数据，三处同日同步。
2. **状态三态**：`正式`（进生产或 M9 正式可选）/ `无效弃用`（三连收尾，版本号划线）/ `不落地`（探底结论，标注日期 + 脚本去留）。
3. **一次性探笔**：不动标准库；结果不成文则三连收尾（回滚文件 + CHANGELOG 折叠 + 报告归档 + 脚本留档/删除）。
4. **查数据去对比表，查时序去 CHANGELOG，查状态来本表**——本页不复制任何一处的完整数据。
